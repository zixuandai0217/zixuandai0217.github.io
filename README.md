# Zixuan Dai's Homepage

这是 [zixuandai0217.github.io](https://zixuandai0217.github.io/) 的源码。

网站基于 [WowPage](https://github.com/wd7ang/WowPage) 与 AcademicPages/Jekyll 构建，沿用 WowPage 的原生布局、字体和配色风格。

## 本地运行

```bash
bundle install
bundle exec jekyll serve
```

浏览器打开 `http://127.0.0.1:4000/`。

## 主要内容位置

- `_config.yml`：网站标题、作者与社交链接
- `_pages/about.md`：首页内容
- `assets/css/home.css`：首页视觉样式
- `assets/js/home.js`：随机灵感交互
- `images/github-avatar.png`：GitHub 头像的本地副本
